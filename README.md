# CST Supermercado - Landing Page Demo

Landing page responsiva para demonstração de um supermercado com pedidos pelo WhatsApp, ofertas e informações de entrega.

---

## 📋 Sobre o projeto

O **CST Supermercado** é uma landing page demonstrativa desenvolvida para apresentar um modelo de site para supermercados e mercados que desejam divulgar produtos, ofertas e receber pedidos pelo WhatsApp.

A página reúne informações importantes para o cliente em uma interface única, incluindo ofertas da semana, categorias de produtos, horários de atendimento, bairros atendidos, entrega e formas de pagamento.

A proposta é demonstrar uma experiência simples e objetiva, facilitando o acesso do cliente às informações e ao canal de pedidos.

---

## ✨ Funcionalidades

* Landing page moderna e responsiva
* Botões de pedido integrados ao WhatsApp
* Lista de ofertas organizada por categorias
* Produtos clicáveis para iniciar pedidos pelo WhatsApp
* Informações sobre entrega e pagamento
* Horários de atendimento configuráveis
* Lista de bairros atendidos
* Exibição dinâmica do status de atendimento
* Tema adaptado ao modo claro e escuro do dispositivo
* Interface otimizada para computadores e dispositivos móveis
* Configuração centralizada para facilitar a personalização

## 🎯 Objetivo do projeto

O objetivo deste projeto é servir como uma demonstração de landing page para supermercados e pequenos comércios que desejam ter uma presença digital simples para divulgar produtos e direcionar pedidos para o WhatsApp.

Além da finalidade demonstrativa, o projeto apresenta conhecimentos relacionados a desenvolvimento front-end, responsividade, organização de interface, experiência do usuário e interatividade com JavaScript.

---

## ⚙️ Personalização

As principais informações da landing page estão centralizadas no objeto `CONFIG` dentro do arquivo `index.html`.

É possível alterar facilmente informações como:

* Nome do supermercado
* Número do WhatsApp
* Endereço
* Bairros atendidos
* Taxa de entrega
* Valor para entrega grátis
* Pedido mínimo
* Horários de funcionamento
* Horário limite para entrega no mesmo dia

As ofertas também podem ser personalizadas diretamente no código.

## 📱 Responsividade

* Computadores

## 🚀 Como executar localmente

### 1. Clone o repositório

```bash
git clone https://github.com/programadorcosta87-eng/supermercado-landing-demo.git
```

### 2. Entre na pasta

```bash
cd supermercado-landing-demo
```

### 3. Execute localmente

Como o projeto é uma landing page independente, basta abrir o arquivo:

```text
index.html
```

diretamente no navegador.

Também é possível utilizar qualquer servidor local para servir o projeto.
